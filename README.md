# tli

Torchlight: Infinite build workspace (Vlad + Claude).

- `docs/mechanics.md` — damage formula and verified game rules
- `docs/tlidb.md` — how to read tlidb.com raw, URL rules, what each page type contains
- `docs/crafting.md` — crafting system and FE costs as observed in game
- `tools/tlidb.py` — fetch a tlidb page and print its text / tables
- `tools/value.py` — "how much is this line worth on my sheet" calculator
- `data/` — scraped game data
- `ss14/thea/` — SS14 Tartarus, Thea (Wisdom of The Gods), Chromatic Shot Spell Tangle cold

Requirements: Python 3.10+, `beautifulsoup4`, `lxml`.
