of that class for this loot, so the page gives no verdict. Loot types with no row at all for a mechanic: that mechanic does not drop it.
Only the classes that matter for planning are listed: flat, generic additional, every typed additional/flat, and the working replicate /
special lines by name. Everything marked 'no' on the page for 'other' lines is left out (dozens of unrelated gameplay lines).
